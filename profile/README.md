## Purpose

This organization holds **production Odoo addons and client delivery repositories** for work led by [Sirelkhatim Gamal](https://github.com/seralkhatem3210) at **Uss Alilm**.

Client implementations are private by default. Public repositories exist only for profile, standards, and documentation.

## What we build

- Custom **Odoo 17 / 18** modules
- Saudi localization (ZATCA, Arabic documents, local HR practices)
- HR, attendance, payroll, and employee portals
- Inventory, CRM, fleet, and accounting extensions
- Payment gateway and messaging integrations
