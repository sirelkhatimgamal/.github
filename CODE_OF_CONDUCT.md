# Code of Conduct

This organization follows a simple professional standard.

## Expected

- Respect clients, colleagues, and reviewers
- Give clear, technical feedback
- Protect private business data

## Not acceptable

- Sharing client data, credentials, or private repositories
- Personal attacks or harassment
- Committing proprietary Odoo Enterprise code to public repositories

## Enforcement

Report issues to the organization owner via [sirelkhatim.uk](https://sirelkhatim.uk) or GitHub.

Adapted from the spirit of the Contributor Covenant.
